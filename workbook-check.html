    What happens to my data?

    The tool reads the file into this page’s memory. It does not upload or persist the workbook. Clear removes the current file and results. Closing the tab ends processing. Your downloaded inventory remains wherever you save it. Avoid shared devices for confidential material.

    What can this check miss?

    It cannot discover business rules outside the file or employee judgment. It does not execute macros, follow external links or verify calculations. Unsupported features are flagged. Formula references are an inventory, not a complete dependency graph or correctness test.
